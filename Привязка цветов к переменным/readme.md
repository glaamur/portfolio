# Привязка цветов к переменным

Инструмент для автоматической замены цветовых значений в CSS на кастомные переменные (`--color-N`).

**[→ Открыть инструмент](https://glaamur.github.io/portfolio/Привязка%20цветов%20к%20переменным/)**

---

## Зачем

При работе с чужим или легаси-кодом часто встречается CSS где цвета прописаны хардкодом по всему файлу. Этот инструмент автоматически находит все цвета и выносит их в `:root` как переменные — после этого менять цветовую схему можно в одном месте.

## Что умеет

- Распознаёт форматы: `#hex`, `rgb()`, `rgba()`, `hsl()`
- Одинаковые цвета получают одну переменную
- Генерирует готовый `:root {}` блок
- Показывает все найденные цвета с превью свотча
- Копирует результат в один клик

## Как использовать

1. Вставьте CSS-код в левое поле
2. Нажмите **→ Конвертировать**
3. Скопируйте результат
4. Вставьте `:root {}` блок в начало вашего CSS

## Пример

**Вход:**
```css
.button {
  color: #ff0000;
  background: rgb(0, 128, 255);
  border: 1px solid #333;
}

.button:hover {
  background: #ff0000;
}
```

**Выход:**
```css
:root {
  --color-1: #ff0000;
  --color-2: rgb(0, 128, 255);
  --color-3: #333;
}

.button {
  color: var(--color-1);
  background: var(--color-2);
  border: 1px solid var(--color-3);
}

.button:hover {
  background: var(--color-1);
}
```

## Стек
